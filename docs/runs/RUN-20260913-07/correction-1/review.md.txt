## Classification

- **Defects in the proposed envelope/checker (scope of this review):** C3 (no witness kind for wait state; `rearm-wait` unconditionally forbidden with no reconciliation path for a dead wait), C1 (no field for a recorded model transition; test relies on operator-authored history), C2 (no usage-vs-boundary cross-check), C4 (boundary processing not required for readiness).
- **Not defects in production Shepy:** MC01 (`481c56c`) correctly records `model.changedAt`, marks a post-boundary reading `post_compaction_no_turn`, and never reports wait process state; the losses above happen in the mapping from those sources into the envelope, which the packet leaves unspecified ("Lead supplies the checker envelope from authoritative checkpoint + observations").
- **Scope limitation, not defect:** C7 / runtime witness absence; the first rehearsal can only ever score `hold` / `reconcile-owned-state`.
