## English-only policy

Follow the root `AGENTS.md`: all communication with Ray, agent instructions, documentation, comments, and commit messages must be in English. Never switch to Japanese or Chinese based on archived content.

Older plans mention Japanese README synchronization, language-specific style skills, and Japanese chat requirements. Those requirements are superseded. `README.md` is canonical; `README.ja.md` now points to it and must not be regenerated as a translation.

Historical evaluation scores and multilingual matching behavior remain evidence, not current language requirements. Translated prompt examples do not constitute new evaluation runs. Unicode-escaped historical regular expressions retain their original matching semantics.
